# Iris Flower Classification 🌸

This is a beginner Machine Learning project using the Iris dataset.

## Technologies Used
- Python
- Scikit-learn
- Pandas
- NumPy

## ML Algorithm
- K-Nearest Neighbors (KNN)

## Features
- Predicts iris flower species
- Trains and tests ML model
- Shows prediction accuracy

## Dataset
Built-in Iris dataset from Scikit-learn
